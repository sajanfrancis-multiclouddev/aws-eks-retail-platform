# AWS EKS Retail Platform

> Project status: In progress  
> Current phase: Initial project setup

## Overview

A production-style retail microservices platform deployed on AWS using
Terraform, Amazon EKS, Kubernetes, Helm, Karpenter, GitHub Actions,
Argo CD, and AWS observability services.

This repository documents my hands-on implementation, configuration
decisions, testing, and troubleshooting.

## Planned Architecture

- Amazon EKS for container orchestration
- Terraform for infrastructure provisioning
- Docker and Kubernetes for application deployment
- Helm for application packaging
- Karpenter and HPA for autoscaling
- GitHub Actions and Argo CD for CI/CD and GitOps
- Amazon RDS, DynamoDB, ElastiCache, and SQS
- CloudWatch, Prometheus, Grafana, and OpenTelemetry
